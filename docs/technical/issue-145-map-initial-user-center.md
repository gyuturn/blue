# #145 지도 첫 화면을 내 위치 기준 확대 화면으로 표시

## 배경
공고 지도 탭을 열면 대한민국 전체(level 13)가 보이거나 공고 핀 전체가 보이도록 범위가 잡혀서,
내 주변 공고를 보려면 매번 확대하거나 📍 내 위치 버튼을 눌러야 했다.

## 변경 (`components/announcements/AnnouncementMap.tsx`)
- **지도 생성 시**: `userPosition`이 있으면 내 위치 중심 + level 7(📍 내 위치 버튼과 동일)로 생성한다.
  없으면 기존처럼 `KOREA_CENTER` + level 13.
  - `userPosition`은 ref(`userPositionRef`)로 읽어 지도 생성 effect의 deps에 넣지 않는다 (지도 재생성 방지).
- **범위 조정 effect**: `userPosition`이 있으면 내 위치 중심 level 7 이동을 **한 번만** 한다
  (`centeredOnUserRef`). 이후 핀 데이터가 늦게 도착해도 `setBounds`를 호출하지 않아 전국으로 축소되지 않는다.
  - 위치 권한이 늦게 허용되어 지도 생성 후 `userPosition`이 들어와도 같은 경로로 한 번 이동한다.
- 📍 내 위치 버튼 동작은 그대로.

## 동작

| 상황 | 첫 화면 |
|------|---------|
| 내 위치 있음 (지도 생성 전) | 내 위치 중심, level 7로 생성 |
| 내 위치가 지도 생성 후 도착 | 그 시점에 내 위치 중심, level 7로 한 번 이동 |
| 내 위치 있음 + 핀 데이터 도착 | 범위 변경 없음 (내 위치 확대 화면 유지) |
| 내 위치 없음, 핀 2개 이상 | 전체 핀이 보이게 `setBounds` (기존) |
| 내 위치 없음, 핀 1개 | 해당 핀 중심, level 6 (기존) |
| 내 위치 없음, 핀 0개 | 대한민국 전체, level 13 (기존) |
| 📍 내 위치 버튼 | 내 위치 중심, level 7 (기존) |

## 리뷰 반영 (보완)
- **다른 지역 선택 시**: 선택 지역이 `전체` 또는 내 지역(`userRegion`)일 때만 내 위치 중심으로 연다(`centerOnUser` prop). 다른 지역(예: 서울 사용자가 '부산' 선택)을 고르면 기존처럼 그 지역 핀 범위로 맞춘다. 내 위치 점과 '📍 내 위치' 버튼은 그대로 보인다.
- **위치가 늦게 도착할 때**: 그 사이 사용자가 지도를 드래그했다면(`dragstart`) 내 위치로 강제 이동하지 않는다.
