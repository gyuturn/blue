# #103 가점 계산기 '주민등록등본' 기준 설명 보강

## 문제
계산기 1단계(집)·3단계(가족)의 "같은 주민등록등본" 표현과 "함께 사는 가족" 제목 때문에,
청약 기준이 **실제 거주**인지 **주민등록(전입신고)** 인지 헷갈린다.

## 정책 기준 (주택공급에 관한 규칙)
- 무주택 판단 단위는 **세대**: 주민등록등본에 함께 오른 세대원 + 배우자(등본이 달라도 포함) + 배우자의 등본상 직계존·비속.
- 부양가족(가점): 배우자, 3년 이상 계속 같은 등본에 있는 무주택 직계존속, 같은 등본의 미혼 자녀.
- 기준은 실제 거주가 아닌 주민등록 등재 여부. 따라서
  - 따로 살아도 전입신고를 옮기지 않았다면 같은 세대
  - 전입신고를 옮겼거나 같은 주소에서 세대분리했다면 다른 세대

## 설계
- 프론트엔드 문구 변경만으로 해결. API·DB·점수 계산 로직 변경 없음.
- `app/calculator/page.tsx`
  - `ResidentRegistrationHelp` 컴포넌트 추가: 기존 `WhyAsk`와 같은 `<details>` 패턴. `context` prop(`'home' | 'family'`)으로 단계별 마지막 문단만 다르게 보여준다.
  - `HomeStep`/`FamilyStep`의 질문 제목·설명·선택지 문구를 등본 기준으로 변경.
- `lib/terms.ts`: '주민등록등본(세대)' 용어 추가 (가이드 용어 사전에 노출).

## 리스크
