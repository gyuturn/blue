# #131 주변 시세: 주소 → 시군구 코드 직접 변환 — 기술 설계

## 배경
#120 주변 시세는 주소 → 카카오 좌표 → 카카오 법정동코드 순으로 실거래가 API의 `LAWD_CD`를 구했다.
운영 카카오 앱의 지도/로컬 API가 비활성(`403 disabled OPEN_MAP_AND_LOCAL service`)이라 모든 공고에서 실패했다(PR #125 진단).
실거래가 API에는 좌표가 필요 없고 시군구 코드만 있으면 되므로 카카오를 제거한다.

## 설계
- `lib/lawdCode.ts`
  - 시군구 코드표 `[코드, 시도, 시군구]` 내장 (구가 있는 시는 `"수원시 장안구"`)
  - `resolveLawd(address)` → `{ lawdCds, dong }`
    1. 괄호 제거 후 공백 분리
    2. 첫 단어를 시도로 정규화 (`서울`, `강원도`→`강원특별자치도`, `전라북도`→`전북특별자치도` 등)
    3. `"시 구"` 2단어 일치 우선 → 구 생략 시(`"수원시 ○○동"`) 하위 구 전체 → 1단어 일치
    4. 시군구 뒤 첫 `○○동/읍/면/가` 단어를 동 이름으로 사용 (없으면 시군구 전체 비교)
- `market-price` 라우트: 카카오 호출 제거, `lawdCds`별 실거래를 합쳐 기존 비교 로직 사용

## 코드표 출처·검증
- 기준: 행정표준 법정동코드(PublicDataReader 1.1.1 번들, 2022-09) 중 현존 시군구
- 개편 반영: 강원(42→51)·전북(45→52) 특별자치도, 군위군(47720→27720), 부천 일반구(41192/41194/41196), 화성 일반구(41591/41593/41595/41597), 인천 구 개편(제물포구 28125·영종구 28155·서구 28275·검단구 28290), 광주·전남(진단 결과에 따라 반영)
- 검증: 전 코드에 대해 실거래가 API 2026-09 조회 → 거래가 잡히는 코드와 법정동 샘플로 확인 (PR #125 진단 로그)
- 하위 구가 있는 시 자체 코드(예: 41110 수원시)는 실거래가 API에 거래가 없어 제외

## 리스크
- 행정구역 개편 시 코드표 갱신 필요 → 못 찾으면 `unknown-sigungu`로 로그를 남기고 "주변 시세를 찾지 못했어요" 표시
- 동 이름이 없는 지구·블록 주소는 시군구 전체 기준
